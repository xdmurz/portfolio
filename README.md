# muratkhan.dev — Personal Portfolio

My personal portfolio website built from scratch with pure HTML, CSS, and JavaScript. No frameworks, no templates.

Live at: **[xdmurz.github.io](https://xdmurz.github.io)**

---

## About

I'm Muratkhan Sartbayev, a 17-year-old developer from Radom, Poland. This site is my developer portfolio — showcasing who I am, what I build, and how to reach me.

---

## Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (IntersectionObserver for scroll animations)
- Google Fonts (DM Sans + DM Mono)

No build tools. No dependencies. Just one file.

---

## Structure

```
/
├── index.html   # entire site — markup, styles, and scripts
├── me.jpg       # photo used in the About section
├── me2.jpg      # photo used in the Hero section
└── README.md
```

## Running locally

Just open `index.html` in your browser. No server needed.
